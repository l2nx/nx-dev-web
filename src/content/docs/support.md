## Integration and access

Write to [support@l2nx.app](mailto:support@l2nx.app). To get an answer faster, include:

- your project: its l2nx.top page or site address;
- what you are trying to do and what happens instead;
- for API errors: the request (method, URL, time in UTC), the status, the `code` and the `traceId` from the
  [error response](/api/overview/#errors);
- for webhooks: the `webhook-id` of the affected delivery, if you have it.

Never send full API keys or webhook secrets. If you think one has leaked, say so: it will be revoked or rotated.

## Security

Report vulnerabilities privately to [security@l2nx.app](mailto:security@l2nx.app), not in public issues. Describe the
issue and the steps to reproduce it. Please give us time to fix it before any public disclosure.

## Documentation

Found a mistake or something missing? [Open an issue](https://github.com/l2nx/nx-dev-web/issues) or use the edit link
at the bottom of any page to propose a fix.
