nx-l2 — сервер Lineage 2 с открытым исходным кодом на основе [L2J Mobius](https://gitlab.com/MobiusDevelopment/L2J_Mobius)
со встроенной интеграцией с платформой L2NX. В одном репозитории лежат все хроники, сервер логина, сетевой стек и общие
библиотеки.

У проекта три задачи:

- **Готовая сборка.** Любой, кто хочет запустить сервер, получает его с интеграцией L2NX из коробки. Без учётных данных
  платформы он работает как обычный эмулятор.
- **Стенд для адаптера.** Каждый релиз [адаптера L2NX](/ru/adapter/overview/) проверяется от начала до конца на живом
  сервере.
- **Разработка сообществом.** Движок развивается открыто.

Как и Mobius, nx-l2 — эталонная реализация для обучения и исследований.

## Состояние

High Five перенесён из L2J Mobius со всей историей. Оба сервера работают на Spring Boot (этап 2): метрики, проверки
состояния, мягкая остановка и образ Docker. См. [быстрый старт](/ru/l2/quick-start/) и
[эксплуатацию](/ru/l2/operations/).

| Этап | Что даёт                                                                       |
| ---- | ------------------------------------------------------------------------------ |
| 1    | High Five с историей, сборка Gradle, локальный запуск                          |
| 2    | Запуск на Spring Boot: метрики, проверки состояния, мягкая остановка           |
| 3    | PostgreSQL, схема через Liquibase                                              |
| 4    | Собственный транспорт на Netty для всех соединений                             |
| 5    | Встроенный L2NX: последняя версия адаптера, команды и события                  |
| 6    | Публичный тестовый сервер                                                      |
| 7    | Движение, поиск пути и линия видимости за одним интерфейсом, вариант с navmesh |
| 8    | Новые клиенты на High Five                                                     |
| 9    | Essence и общее ядро двух хроник                                               |
| 10   | Interlude                                                                      |

Каждый этап заканчивается сервером, который собирается, и клиентом, который заходит и играет.

## Структура

Целевая структура; в репозитории есть `libs/boot`, `libs/network`, `engine/core` (пока только игровые часы),
`login/` и `chronicles/high-five/`.

```
libs/          инфраструктура без знаний о Lineage 2
engine/        механики, общие для всех хроник
login/         один сервер логина для всех хроник
chronicles/    по каталогу на хронику: server, scripts, datapack, boot
tools/         подготовка данных из собственного клиента оператора
```

Хроника держит код и данные в одном каталоге, поэтому они меняются вместе. Квесты, поведение NPC и обработчики —
отдельный компилируемый модуль `scripts`, собранный поверх сервера хроники.

## Чего в репозитории нет

Нет игрового клиента, ресурсов клиента, геодаты, декомпилированного или утёкшего кода. Операторы готовят данные из
собственного клиента. Откуда взят код — в разделе [лицензии](/ru/l2/licensing/).
