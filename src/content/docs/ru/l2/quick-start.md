---
title: Быстрый старт
description: Собрать nx-l2 и запустить на своей машине базу данных, сервер логина и игровой сервер High Five.
---

Нужны JDK 25 и Docker. На Windows клонируйте с `git clone -c core.longpaths=true`: часть путей к скриптам длиннее,
чем Windows допускает по умолчанию.

## База данных

```sh
docker compose up -d
```

Команда запускает MariaDB на `127.0.0.1:3306` и при первом старте создаёт базу `l2nx` с полной схемой. Это совпадает с
настройками обоих серверов по умолчанию (`spring.datasource.*`): пользователь `l2nx`, пароль `l2nx`. Порт открыт только для
вашей машины; прежде чем открывать базу куда-то ещё, смените пароль и задайте такой же серверам в
`config/application.yaml` (см. [эксплуатацию](/ru/l2/operations/)). На этапе 3 база переходит на PostgreSQL.

## Серверы

```sh
./gradlew :login:boot:run
./gradlew :chronicles:high-five:boot:run
```

Сервер логина принимает клиентов на порту `2106`. Игровой сервер регистрируется на нём и принимает клиентов на порту
`7777`. Аккаунт создаётся при первом входе (`AutoCreateAccounts` в `Server.ini` сервера логина).

Принимаются клиенты High Five с ревизиями протокола 267, 268, 271 и 273 (`AllowedProtocolRevisions` в `Server.ini`
игрового сервера).

## Дистрибутивы

```sh
./gradlew installDist
```

собирает два готовых к запуску каталога:

| Каталог                                               | Содержимое                                                                       |
| ----------------------------------------------------- | -------------------------------------------------------------------------------- |
| `login/boot/build/install/login-server`               | `bin/login-server`, `config/`                                                    |
| `chronicles/high-five/boot/build/install/game-server` | `bin/game-server`, `config/`, `data/`                                            |

Серверы работают без графического интерфейса. Рестарт из игры или по расписанию завершает процесс с кодом 2, падение —
другим ненулевым кодом, остановка — кодом 0: запускайте сервер под супервизором, который перезапускает его при ненулевом
коде (systemd `Restart=on-failure`, Docker `restart: on-failure`; примеры в [эксплуатации](/ru/l2/operations/#перезапуск)). `./gradlew distZip` упаковывает те же каталоги в архивы.

Сборка перезаписывает в этих каталогах всё, что приходит из исходников, включая `config/`. Сохраняются `log/` и
`data/geodata/`.

## Геодата

Геодата не поставляется. Положите файлы в `data/geodata` каталога игрового сервера; формат и путь задаются в
`config/GeoEngine.ini`.
