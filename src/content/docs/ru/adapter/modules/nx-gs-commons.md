Утилиты, общие для модулей адаптера: помощники для конкурентности, хеширование, работа с null и помощники для
поиска сервисов.

## Координаты

```text
app.l2nx:nx-gs-commons
```

Java 8. Тег релиза `commons/vX.Y.Z`. Версии — на
[Maven Central](https://central.sonatype.com/artifact/app.l2nx/nx-gs-commons).

## Когда нужен хосту

Приходит транзитивно с [`nx-gs-adapter-core`](/ru/adapter/modules/nx-gs-adapter-core/) и модулями синхронизации;
объявлять его не нужно.

## Идентификаторы клиента

`ClientIdentifiers` (`hwid`, `ip`) нормализует hwid и IP клиента на границе wire. Клиенты и хосты подставляют вместо
отсутствующего значения заглушки (`N/A`, `0`, `-`, UUID или адрес из одних нулей, `::`, пустую строку); такое
значение становится `null`, поэтому несвязанные игроки не склеиваются в лимите на устройство, бане или подсчёте
уникальных. Настоящее значение возвращается обрезанным и в остальном как есть.

## Конфигурация

Своих ключей нет.
