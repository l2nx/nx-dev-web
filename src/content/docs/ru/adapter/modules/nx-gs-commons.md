Утилиты, общие для модулей адаптера: помощники для конкурентности, хеширование, работа с null и помощники для
поиска сервисов.

## Координаты

```text
app.l2nx:nx-gs-commons
```

Java 8. Тег релиза `commons/vX.Y.Z`. Версии — на
[Maven Central](https://central.sonatype.com/artifact/app.l2nx/nx-gs-commons).

## Когда нужен хосту

Приходит транзитивно с [`nx-gs-adapter-core`](/ru/adapter/modules/nx-gs-adapter-core/) и модулями синхронизации;
объявлять его не нужно.

## Конфигурация

Своих ключей нет.
