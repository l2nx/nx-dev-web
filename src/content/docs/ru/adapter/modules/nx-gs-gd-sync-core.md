Публикует игровые данные, которые сервер разобрал из датапака: шаблоны предметов, NPC, скиллов, рецептов, сетов
брони, кристаллов душ, классов и инстансов, опции предметов с каталогом аугментации (life stone и группы целей),
уровни опыта и правила gear score. Платформа использует их как каталоги
для вики, маркета и gear score. Модуль публикует то, что сервер держит в памяти после своих переопределений, поэтому
каталог совпадает с игрой.

## Координаты

```text
app.l2nx:nx-gs-gd-sync-core
```

Java 8. Тег релиза `gd-sync/vX.Y.Z`. Версии — на
[Maven Central](https://central.sonatype.com/artifact/app.l2nx/nx-gs-gd-sync-core).

## Когда нужен хосту

Когда предметы, NPC и скиллы сервера должны появиться на платформе ровно такими, какие они в игре.

## Что предоставляет хост

- Провайдер для каждого каталога, который он отдаёт (список — в
  [`nx-gs-adapter-api`](/ru/adapter/modules/nx-gs-adapter-api/#что-реализует-хост)). Каталог без провайдера не
  публикуется.
- По желанию — `GameDataReadinessProvider`, который сообщает, что датапак загружен. Без него модуль сразу считает
  данные готовыми; с ним модуль ждёт, и снапшот никогда не снимается с недозагруженных данных.
- Вызов `NxGameData.publishSnapshot()` после перезагрузки датапака сервером, чтобы платформа сразу получила новые
  данные. Модуль хоста получает `NxGameData` из `ConnectContext.gameData()`.

Первый снапшот модуль публикует сам после подключения. Платформа тоже может запросить полную переотправку, а
`l2nx.gd-sync.resync-interval-hours` добавляет периодическую.
