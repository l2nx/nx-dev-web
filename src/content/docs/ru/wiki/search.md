Окно поиска вики и списки вики работают по общим правилам поиска L2NX: длина запроса, синтаксис, id, опечатки,
неверная раскладка и порядок результатов описаны на странице [Поиск](/ru/guide/search/). Здесь — только то, что вики
ищет у каждого вида записей.

## Что ищется

| Запись     | Id                          | Названия и текст                                                                    |
| ---------- | --------------------------- | ----------------------------------------------------------------------------------- |
| Предметы   | id предмета                 | название на всех языках, в том числе изменённое командой сервера и исходное         |
| Умения     | id умения                   | название на всех языках, в том числе изменённое; все уровни умения — одна запись    |
| NPC        | id NPC                      | имя и титул, в том числе собственные имя и титул NPC на сервере                     |
| Классы     | нет: `#N` ничего не находит | название на всех языках и токен класса (`GLADIATOR`)                                |
| Статьи     | id статьи (UUID)            | заголовок, краткое описание, категория и её родительская категория; не текст статьи |
| Рейд-боссы | id NPC                      | имя                                                                                 |
| Осады      | id замка                    | название замка и название клана — владельца замка                                   |
| Ивенты     | нет                         | название и код ивента                                                               |

- Рейд-боссы, осады и ивенты ищутся в расписании событий: в каждой категории остаются совпавшие записи.
- Статья совпадает сначала по заголовку, затем по краткому описанию, затем по категории: при одинаково сильном
  совпадении выше совпадение в заголовке.
- Записи, которые команда сервера скрыла из вики, в поиске не появляются.

## Популярность

Среди записей с одинаково сильным совпадением выше та, которую чаще смотрят. Популярность — число просмотров страницы
за последние 30 дней:

- у предметов, умений, NPC и классов считаются просмотры на сервере, который вы смотрите;
- у статей — просмотры самой статьи.

У расписания событий популярности нет: его записи идут только по силе совпадения.
