[l2nx.top](https://l2nx.top) — рейтинг и календарь открытий серверов Lineage 2. Игроки голосуют там за проекты, а вы
можете награждать их за это: каждый голос может нести ваш идентификатор игрока и возвращается к вам.

## Проекты и серверы

**Проект** — весь бренд вашего игрового сервера: один сайт, один slug (`https://l2nx.top/{tenantSlug}`), один или
несколько игровых серверов. Голосуют за проект. В голосе можно указать один из ваших серверов, но засчитывается он
всегда проекту.

Голоса принимаются, только пока проект размещён на l2nx.top. Закрытый или скрытый проект и сервер, которого нет в
списке, голосов не получают.

## Как проходит голос

1. Вы отправляете игрока по [ссылке для голосования](/ru/top/vote-link/): `https://l2nx.top/{tenantSlug}/vote`,
   обычно с `ref`, который определяет игрока на вашей стороне.
2. Игрок проходит проверку Cloudflare Turnstile и голосует. Аккаунт на l2nx.top игроку не нужен.
3. Голос записывается вместе с вашим `ref` ровно в том виде, в каком вы его передали, и доставляется вам:
   - на ваш эндпоинт [вебхуком `vote.created`](/ru/top/webhooks/);
   - в ленту голосов [Integration API](/ru/api/overview/) по вашему API key.
4. Вы находите игрока по `ref` и выдаёте награду.

:::note
l2nx.top не интерпретирует `ref`. Он не знает ваших игроков и не может проверить, что проголосовал именно тот игрок,
на которого указывает `ref`. Какие голоса заслуживают награды, решаете вы на своей стороне.
:::

## Кулдаун

Один голос за проект раз в **24 часа** от одного голосующего. Голосующий определяется по:

- **сетевому адресу**: адрес IPv4 или сеть `/64` для IPv6;
- **браузеру**: долгоживущей cookie, которую ставит l2nx.top.

Голос отклоняется, если за последние 24 часа за этот же проект уже голосовали с того же адреса **или** из того же
браузера. Выбранный в голосе сервер роли не играет: один голос на проект, а не на сервер. Страница голосования
показывает игроку, когда можно проголосовать снова.

Кулдауны проектов независимы: голос за другой проект на ваш не влияет.

:::caution
Игроки за одним публичным адресом (общая квартира, интернет-кафе, NAT мобильного оператора) делят один кулдаун. Не
обещайте награду каждому аккаунту одного человека.
:::

## Рейтинг

Рейтинг l2nx.top курируется по опубликованным принципам, а не считается простым числом голосов:

- голоса на l2nx.top за текущий календарный месяц (UTC);
- присутствие и позиция проекта на других топах Lineage 2;
- недавние и предстоящие открытия серверов.

Веса не публикуются, число голосов и score не показываются никому. Рейтинг пересчитывается каждый час, месячный счёт
голосов начинается заново в начале каждого месяца по UTC. Лишний голос никогда не работает против проекта.

Платные размещения показываются отдельным блоком с пометкой о рекламе. Они покупают показ, а не позицию: продвигаемый
проект остаётся на своём честном месте в рейтинге.

Ваши голоса видите только вы: лента голосов отдаёт голоса того проекта, которому принадлежит API key.
