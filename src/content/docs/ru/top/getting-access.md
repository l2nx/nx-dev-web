[Ссылка для голосования](/ru/top/vote-link/) работает для любого размещённого проекта без настройки. Чтобы получать
голоса обратно, нужно одно из двух или оба:

- **эндпоинт вебхука**, принимающий [`vote.created`](/ru/top/webhooks/);
- **API key** со scope `top.votes:read` для ленты голосов и поиска по `ref` (см.
  [Аутентификация](/ru/api/authentication/)).

Пока нет кабинета владельца проекта, и то и другое настраивается по запросу.

## Как запросить

Напишите на [support@l2nx.app](mailto:support@l2nx.app) и укажите:

- проект: его страницу на l2nx.top (`https://l2nx.top/{tenantSlug}`) или адрес сайта;
- что нужно: вебхук, API key или оба;
- для вебхука: URL эндпоинта (`https://`, порт 443, доступен из интернета; см.
  [требования к эндпоинту](/ru/top/webhooks/#требования-к-эндпоинту));
- для API key: его название (например, `site-production`) и срок действия, если он нужен;
- технический контакт для проблем с доставкой.

Если не знаете slug проекта или серверов для [ссылок для голосования](/ru/top/vote-link/), спросите в том же письме.
Поддержка может попросить подтвердить, что проект ваш.

## Что вы получите

- **Секрет вебхука** `whsec_…` — для [проверки подписи](/ru/top/webhooks/#проверка-подписи).
- **API key** `nx_api_…`.

Оба показываются один раз. Храните их в конфигурации сервера или хранилище секретов, но никогда — в клиентском коде,
игровом клиенте или публичном репозитории.

## Изменения и ротация

Напишите на тот же адрес, чтобы:

- **сменить URL вебхука**: секрет остаётся прежним;
- **сменить секрет вебхука**: 24 часа доставки подписываются и старым, и новым секретом, поэтому переключиться можно
  без потери событий;
- **заменить API key**: выдаётся новый ключ, а старый продолжает работать; отзовите старый, когда переключитесь;
- **отозвать ключ**, который мог утечь: пишите сразу.

У проекта может быть несколько активных API keys, например по одному на окружение.
