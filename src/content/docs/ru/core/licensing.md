Лицензия назначается каждому файлу по спецификации [REUSE](https://reuse.software). Каждый файл указывает свою лицензию
и правообладателя — в заголовке или в `REUSE.toml`, и CI это проверяет.

| Файлы                                                      | Лицензия   |
| ---------------------------------------------------------- | ---------- |
| новые и переписанные файлы                                 | Apache 2.0 |
| файлы L2J Mobius с заголовком MIT                          | MIT        |
| файлы L2J Mobius с заголовком GPLv3                        | GPLv3      |
| файлы L2J Mobius без заголовка (данные, SQL, конфигурация) | MIT        |

## Что это значит для сборки

Пока в сборке остаётся хотя бы один файл под GPLv3, сборка целиком распространяется под GPLv3: любой может её
распространять и изменять вместе с исходниками. Запуск сервера без передачи сборки кому-либо распространением не
является.

GPLv3 вытесняется, а не сохраняется:

- В `libs/` и `engine/` нет ни одного файла под GPLv3, поэтому их может использовать любой эмулятор, в том числе
  закрытый.
- Модуль хроники становится пермиссивным, когда переписан его последний файл под GPLv3. CI выводит число таких файлов
  по модулям.
- Файл под GPLv3 переписывается по поведению, а не правкой его текста.

## Откуда взят код

nx-l2 основан на L2J Mobius. Хроника High Five перенесена со своей историей из upstream-коммита `5ddd6ff4b98`. Файлы из
Mobius сохраняют upstream-уведомления об авторских правах и лицензии; файл, изменённый в nx-l2, получает строку
`2026 L2NX contributors` и сохраняет свою лицензию.

Игровые механики можно сверять с другими серверами только по поведению. Код, данные и структура из них не
копируются, декомпилированный, утёкший и проприетарный код не принимается.

## Вклад в проект

Вклад попадает под лицензию файла, который он затрагивает. Новый файл — Apache 2.0.
